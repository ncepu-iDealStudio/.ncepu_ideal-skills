# 权限推断与默认策略

用于门禁通过之后、只有 SQL 和 CRUD 项目、没有完整权限矩阵的输入。目标是产生保守且可用的鉴权设计，不声称能从表结构还原真实产品全部权限。

登录接口缺失、登录不符合令牌要求、以及已发现多种用户角色但权限范围未说明时，必须按[预检与门禁](preflight-and-gates.md)停止并询问，不能用本文件的默认选择跳过这些门禁。门禁之外的常规 CRUD 权限仍按下列优先级处理，不要为每个接口反复提问。

## 规则来源

按以下优先级决定，并在项目的一份简短权限说明中标记来源：

1. **用户明确规则**：优先执行；与现有代码冲突时说明改动。
2. **证据推断**：综合现有认证代码、Service 查询、外键、唯一约束、字段注释及关系链推断。字段名和合成数据可以提供线索，但单独一个 `user_id` 或数值相等不足以证明所有权；外键也可能表示创建者、审核者或收件人，需结合用途判断。
3. **默认选择**：证据不足时按下表设计，不等待用户批准每个常规实现选择。与可信的已有限制冲突时保留原限制，不用默认规则扩大既有权限。

## 默认权限

| 对象或操作 | 默认选择 |
| --- | --- |
| 公开入口 | 仅门禁确认的登录，以及项目中真实存在的健康检查与文档入口，精确到方法和路径；业务接口不默认匿名公开。注册/验证码等候选入口未确认前按受保护处理。 |
| 身份与角色 | 发现 `user_type` / 角色表等不同类型用户时，先停问权限范围，不得在此用默认矩阵代替。完全没有角色设计时，才建立最小 `user` / `admin`。管理员须经受控初始化或可信管理操作建立，不能按用户名、注册顺序、组 ID `1` 或客户端角色参数自动赋予。 |
| 本人账号 | 普通用户可读取本人安全资料、修改明确列出的普通资料字段；不允许修改角色、余额、权限状态等。普通账号 CRUD 响应不返回口令、哈希、安全问题答案、恢复令牌等认证或账号恢复秘密，管理员响应同样适用；邮箱等个人资料则按实际用途限制范围。 |
| 有可信归属的可编辑个人资源 | 普通用户默认可读取、创建、修改、删除自己的普通可编辑对象（如个人内容）；列表仅返回本人对象。创建由服务端绑定本人，更新不得认领或转移他人数据；状态、金额、权限及关联字段单独限制。关联父对象还须通过相应访问检查。归属只决定对象范围，不证明某种操作本来就应允许。 |
| 系统生成的流水、审计及权限记录 | 不因记录属于本人就开放本人写入或删除；缺少其他规则时，普通用户最多读取允许公开给本人的字段。涉及余额或权限的修改走受控管理或业务入口，不作为普通资料 CRUD。 |
| 系统配置、字典、无可信本人归属的普通资源 | 保留管理员必要的原有 CRUD，普通用户拒绝；不要因为缺少业务说明将管理员也全部拒绝。管理员仍受敏感字段限制，不能原样开放凭据、任意身份绑定或提权入口。 |
| 特殊角色或复杂业务 | 不凭空补全教师授课范围、CMS 完整权限体系等；没有证据时先使用上述最小角色策略，说明功能边界。 |

已有记录的归属不能靠姓名相似、相同编号或查询结果第一行认领。缺少账号关联时，可以增加显式绑定表和受控配置方式；未绑定的旧记录仅走管理员适用的管理入口，不让普通用户访问。测试用 A/B 的绑定由测试 fixture 显式建立，不能冒称已经迁移历史数据。若完全无法安全建立对象关系，保留管理员保护并报告水平越权业务场景受阻，不用假对象或全员拒绝制造通过。

受控空库中可以新建管理员身份及对应角色映射；面对已有组或账号，应验证既有权限依据，或创建新的明确管理身份，不能直接把某个现有组提升为管理员来完成初始化。若资源已有访问组、付费或访问口令等限制迹象，“已发布”不能单独证明普通用户可读；语义不明时先限制相关内容访问，保留管理入口并说明边界，不必实现完整付费或内容解锁系统。正文、播放/下载地址和关联内容的检查见[风险备忘录](business-risk-notes.md)的 R10。

对已有账号 CRUD，尽量保留安全管理操作：设置口令走统一哈希，响应去除凭据，角色变更仅限可信管理路径。无法安全兼容的具体旧入口可拒绝并解释原因，但不能因一个敏感字段而关闭整组可安全保留的普通操作。

## 最小可运行交付

- 选择唯一稳定的主体标识。没有可用账号来源时可增加最小认证表；不可在多张候选表之间根据同名账号自动串用身份。
- 为首次运行提供受控的管理员初始化方法，或复用明确可用的既有方法；凭据经环境变量或安全交互输入，不提供通用默认密码或公开无条件初始化 API。测试账号由 fixture 创建，不作为交付后的后门。
- 新增映射表或密码列扩容需要可复跑的迁移文件/命令及授权边界。可在已授权的独立测试库执行；原数据无法安全迁移时记录限制，不自动重置旧密码或套用示例身份。
- 保留原启动方式，补全无真实秘密的配置示例、所需依赖和相应锁文件。说明初始化、启动和测试命令；不要求实现完整注册、密码找回或账号生命周期平台。
- 权限说明以方法、路径、角色、对象范围、字段限制和规则来源为主；记录暂时关闭的具体操作及理由。默认策略与真实业务适配程度交由后续使用者调整，不能把策略选择包装为数据库中已有的事实。
