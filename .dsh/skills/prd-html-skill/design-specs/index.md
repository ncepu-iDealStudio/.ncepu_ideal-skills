# 设计规范库索引

> 本目录存放设计规范，随 skill 使用自由增删。开工时先读本文件，列出规范清单供用户选择。

## 新增一条规范（用户提出"按 XX 风格"且库中没有时）

```
① 确定来源（任选其一）：
   · 用户发截图    → 提取配色/组件/布局
   · 用户发设计文档 → 读取生成
   · 用户口头描述  → 按描述编写
② 生成规范文件：design-specs/<名称>.md（参考后台-通用.md 的结构）
③ 在本文件登记：名称/适用类型/文件
④ 告知用户新规范已登记，以后开工时会出现在选型清单中
```

## 选型规则（开工时，选型未定禁止开工）

1. **每次开工必问**：列出本清单让用户选（附推荐），等答复后再开工。不得依据用户描述或材料风格自动命中某套规范，无兜底
2. 用户所选不在库中 → 走"新增一条规范"流程，先配规范再开工（截图 / 设计文档 / 用户描述）

## 修改与删除

- 修改：直接编辑对应规范文件（建议同步更新登记行的状态）
- 删除：删文件 + 删本清单登记行（删除前列出清单确认）
