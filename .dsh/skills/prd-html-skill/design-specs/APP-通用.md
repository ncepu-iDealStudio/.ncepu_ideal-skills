# APP-通用 设计规范

> 适用：移动端 APP（iOS/Android 通用，竖屏手机）。
> 基准：iOS 人机界面指南 + Material Design 的通用做法，适配国内 APP 习惯。
> 状态：📋 新建内置。项目级差异（品牌色）在项目 `spec/_公共规范.md` 中覆盖，本文件保持通用。

## 布局框架

- 设计基准宽度 375pt（iPhone 尺寸），高度不限（内容滚动）
- 页面结构三层：
  - **顶部导航栏**：高 44pt，白底，左侧返回箭头，中间标题 17pt 加粗，右侧操作（可选）
  - **内容区**：浅灰底（#F5F5F5），滚动
  - **底部 TabBar**（一级页面才有）：高 49pt，白底上边框 1px，3-5 个 Tab，选中项主色
- 登录/引导页独立，不套 Tab 框架
- 底部考虑安全区（iPhone 底部留白 34pt 左右）

## 色板

| token | 值 | 用途 |
|-------|-----|------|
| --color-primary | #1677FF | 主色：主按钮、Tab 选中、链接、开关开启 |
| --color-success | #52C41A | 成功：完成态 |
| --color-warning | #FAAD14 | 警告：待处理 |
| --color-danger | #FF4D4F | 危险：删除、失败 |
| --color-bg | #F5F5F5 | 页面背景 |
| --color-card-bg | #FFFFFF | 卡片、列表、导航栏背景 |
| --color-text-main | #1F2329 | 主要文字 |
| --color-text-secondary | #646A73 | 次要文字 |
| --color-text-muted | #8F959E | 辅助文字、占位 |
| --color-border | #E5E6EB | 分隔线、边框 |

## 字体

- 字体栈：`-apple-system, "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`
- 导航栏标题 17pt/600，列表主文字 16pt/400，卡片标题 15pt/500，辅助文字 13pt/400，按钮文字 16pt/500
- 正文行高 1.4-1.6

## 间距与圆角

- 页面边距 16pt，卡片间距 8-12pt，列表项内边距 12-16pt
- 圆角：卡片 12pt，按钮 8pt，输入框/标签 6-8pt，头像/图标圆形
- 触控目标：最小 44×44pt（按钮、列表点击区）

## 组件

| 组件 | 规格 |
|------|------|
| 底部 TabBar | 高 49pt，图标+文字（10-11pt），选中主色，图标 24-28pt |
| 顶部导航栏 | 高 44pt，白底，返回箭头 24pt 靠左，标题居中，右侧文字/图标操作 |
| 列表项 | 白底卡片，左图标 24pt + 主文字 16pt + 副文字 13pt 灰 + 右侧灰色箭头 `>`，点击有按压反馈 |
| 分组列表 | 同组连成卡片，组间距 8-12pt，组标题 13pt 灰 |
| 主按钮 | 主色填充白字，圆角 8pt，高 44pt，全宽（页面底部或表单内），hover 变深（移动端为按压态） |
| 次级按钮 | 白底，1px 主色边框，主色字，高 40pt |
| 危险操作 | 红字按钮/文字链接，删除场景弹确认 |
| 搜索栏 | 圆角输入框，浅灰底（#F5F5F5），放大镜图标在左，placeholder 居中 |
| 卡片 | 白底圆角 12pt，可带标题行 + 分割线 + 内容区 |
| 表单 | label 16pt + 输入框无边框（底线式），错误红字 12pt |
| 弹窗 Dialog | 居中白底圆角 12pt，标题 17pt + 内容 + 双按钮（取消/确定），遮罩半透明黑 |
| 底部操作表 ActionSheet | 从底部滑出，选项列表 + 取消按钮，白底圆角顶部 |
| Toast | 居中深色半透明圆角提示，1.5-2s 自动消失 |
| 空状态 | 居中灰色插画 + 主文字"暂无XX" + 辅助说明 + 可选行动按钮 |
| 骨架屏 | 内容加载时灰色块占位，替代转圈 |
| 角标 Badge | 红色小圆点/数字，挂 Tab 图标右上角 |

## 状态与反馈

- 点击必须有按压反馈（按钮变暗/列表行高亮）
- 提交类操作：按钮 loading 态防重复提交
- 下拉刷新 / 上拉加载更多：列表页标配
- 不可逆操作（删除/解绑）：弹窗或 ActionSheet 二次确认
