# 后台-通用 设计规范

> 适用：后台管理类产品（列表/表单/详情/数据看板页面）。
> 基准：Ant Design（国内后台事实标准），兼容 Element 系规格。
> 状态：✅ 内置。项目级差异（品牌色）在项目 `spec/_公共规范.md` 中覆盖，本文件保持通用。

## 布局框架

- 后台页面统一：左侧 200px 侧边栏 + 顶部 56px 导航栏 + 内容区
- 侧边栏：深色底（#001529），菜单项高 40px，选中项主色高亮，子菜单缩进 16px
- 顶部导航：白底，左侧放面包屑或页面标题，右侧放用户信息/通知
- 内容区：浅灰底（#F5F7FA），内容用白色卡片承载，卡片间距 16px
- 登录页独立，不套后台布局

| --color-warning | #FAAD14 | 警告：待处理、黄色标签 |
| --color-danger | #F5222D | 危险：删除、失败、驳回 |

## 字体

- 字体栈：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`
- 主标题 20px/600，副标题 18px/500，页面标题 16px/500，正文 14px/400，表格 13px，辅助 12px
- 行高：正文 1.5 倍

## 间距与圆角

- 间距基准 8px：紧凑 8、常规 12-16、区块 16-24、页面边距 16-24
- 圆角：小型组件（按钮/输入框/标签）4px；容器（卡片/弹窗/表格头）8px

## 组件

| 组件 | 规格 |
|------|------|
| 主按钮 | 主色填充白字，圆角 4px，高 32px，hover 变深 |
| 次按钮 | 白底，1px 主色边框，主色字，高 32px |
| 危险按钮 | 危险色填充白字（或白底红边），删除确认场景 |
| 表格 | 表头 #FAFAFA 加粗 13px，行高 44px，斑马纹（奇数行 #FAFAFA），hover 高亮，底部分页 |
| 表单 | 标签左对齐，输入框高 32px，1px #DCDFE6 边框，focus 主色边框，错误红字提示 |
| 弹窗 | 居中，白底，圆角 8px，标题 16px，右上角关闭，底部按钮区（取消+确定） |
| 分页器 | 页码 + 上一页/下一页 + 总数，当前页主色高亮 |
| 标签 Tag | 圆角 4px，padding 4-8px，状态色浅底深字（成功/警告/危险） |
| Tab 页签 | 下划线式，选中项主色下划线 2px |
| 面包屑 | 灰色文字，分隔符 `/`，末级深色 |
| 下拉菜单 | 点击展开，白底阴影，选项 hover 浅蓝底 |
| 空状态 | 居中灰色插画/图标 + 辅助文字"暂无数据" |
| 加载 | 转圈或骨架屏（表格可先显示骨架） |

## 状态与反馈

- 操作成功：Toast 或行内提示；失败：红色错误提示（表单内联错误优先）
- 删除/驳回等不可逆操作：弹窗二次确认
- 列表操作列：主操作用文字链接，危险操作红色
