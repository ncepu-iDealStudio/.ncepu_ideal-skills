# 01-登录页

> 每页一个文件。一屏看完，超长拆页。生成 HTML 时只读本文件 + 公共规范 + 导航地图。

## 编写约束（写 spec 时遵守）

- ✅ 只写**用户需要什么**（本页有哪些内容、什么交互）
- ❌ 不写**怎么实现**（不要出现 table 标签、CSS 颜色、代码结构）——样式归公共规范管，实现归生成 HTML 时管
- ❓ 用户没说明白的地方，**不许猜**：标记 `[NEEDS CLARIFICATION: 具体问题]`，生成前停下来问用户

## 基本信息

- **HTML 文件名**：01-login.html（与导航地图一致）
- **导航来源**：无（入口页）
- **跳转目标**：登录成功 → 02-order-list.html（必须在导航地图登记）

## 布局

```
居中卡片（宽 380px）
  ├─ 系统 Logo + 名称
  ├─ 账号输入框
  ├─ 密码输入框
  ├─ 登录按钮（主色，全宽）
  └─ 底部版权文字（灰色小字）
背景：浅灰，卡片白色带投影
```

## 元素与交互

| 元素 | 说明 | 交互 |
|------|------|------|
| 账号输入框 | placeholder：请输入账号 | 无 |
| 密码输入框 | placeholder：请输入密码 | 无 |
| 登录按钮 | 文案：登 录 | 点击 → 跳转 02-order-list.html |
| 空输入提示 | 提交时校验 | 为空则按钮下方红字提示"请输入账号/密码" |

## 状态

- 默认态、输入态、校验失败态（红字提示）、（可选）加载态

无（登录页不需要假数据，演示时任意输入即可登录）
