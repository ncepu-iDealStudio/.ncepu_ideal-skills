# 公共规范（通用骨架）

> 所有产品类型共享的 token 骨架。布局和类型组件在 `design-specs/` 按类型选取，色板值按项目替换。
> 拼装规则：**项目的 `spec/_公共规范.md` = 本骨架 + design-specs 中选定的类型规范 + 项目色板替换**。

## 色板结构（token 名固定，值按项目替换）

| token | 默认值 | 用途 |
|-------|--------|------|
| --color-primary | 按项目 | 主色：按钮、选中态、链接 |
| --color-bg | 按项目 | 页面背景 |
| --color-text-main | 按项目 | 正文 |
| --color-text-secondary | 按项目 | 次要文字 |
| --color-border | 按项目 | 边框、分隔线 |
| --color-danger | 按项目 | 删除、异常 |

> 取值来源：项目截图、设计文档、或用户指定。未指定时取 `design-specs/` 中该类型的默认色板。

## 字体基线

- 字体栈：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`
- 正文 14px，标题 16-20px，表格 13px

## 间距基线

- 页面边距 16-24px，模块间 16px，表单行间 12px

## 视觉签名（每项目必填）

- 一句话描述本项目的**标志性元素**——整个原型只花一次大胆的地方（如首页 hero 区、某页的卡片动效、配色主角），其余页面保持克制
- 取值来源：用户指定 / 截图提取 / 选型默认；未指定时用选型默认值，**首屏生成时在聊天中告知假设（1 句话）**，用户可随时改
- 生成时：页面体现签名元素；回看时对照它检查

## 文案基调（每项目必填）

- **用户视角命名**：按钮/字段按人认识和控制的词命名（"管理通知"，不是"webhook 配置"）
- **主动语态**：控件说清做什么（"保存更改"，不是"提交"）
- **错误/空状态写方向**：说明发生了什么 + 怎么修复（如"暂无报修记录，点击下方按钮提交第一条"），不写情绪
- 同一动作全流程保持同名（按钮"发布" → 提示"已发布"）

## 使用规则

- 类型规范（布局/组件）与通用骨架冲突时，**类型规范优先**
- 项目色板与类型默认色板冲突时，**项目色板优先**
