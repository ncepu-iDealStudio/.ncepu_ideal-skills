# 单文件原型契约

产物是需求评审用的低保真原型，不是上线页面。

## 文件

- 默认一个 HTML：`原型-{系统名称}.html`，与源 md 同目录。`{系统名称}` 取文档标题，去掉空格和 `\ / : * ? " < > |`。连字符用普通 ASCII `-`。
- 用户明确要求多文件时才拆开。拆开后每个文件仍然遵守下面的内联规则。
- 侧栏切换用同一文件里的视图显隐，不靠新开页面。

## 外部资源

只允许这一处外部脚本，用于排版：

```html
<script src="https://cdn.tailwindcss.com"></script>
```

其余 CSS 放在该文件的 `<style>`，其余 JS 放在该文件的 `<script>`。不要再加 CSS CDN、图标库、字体、图片 URL，也不要另存 `.css` / `.js`。`modern-web-guidance` 的建议写进内联脚本，不为它增加第二个外链。

没有网络时，Tailwind 类名不会生效，但文件仍应能打开并完成按钮和表格的交互。不要把只有 Tailwind 才能看懂的结构当成唯一骨架。

## 必须有的交互

文档里出现了对应界面时才做：

- 侧栏切换视图
- 新增或编辑用弹窗，能打开和关闭
- 表格的查询和重置只按文档中的筛选项过滤当前假数据
- 提交成功用页面内提示，不使用 `alert`
- 弹窗里文档标明必填的字段，空值时不关闭弹窗

假数据变量放在内联脚本里，命名以 `MOCK_` 开头。行数据的键与 md 字段对应。

## 不要做的

- 高保真视觉、品牌插画、复杂动效
- 真实接口、登录鉴权、持久化到服务器
- 文档没写的列、筛选项和按钮
