# 离线 HTML 与交互契约（interaction-contract）

本文件只规定单个 HTML 的内部结构、离线约束与交互实现深度。
产物写到哪里、如何命名见 `output-contract.md`；端识别与状态文件内容见 `intake-and-state.md`。

## 1. 离线页面骨架（每个 HTML 必须满足）

- 首行声明 `<!DOCTYPE html>`，根元素写 `<html lang="zh-CN">`。
- `<head>` 内含 `<meta name="viewport" content="width=device-width, initial-scale=1">` 与非空且有意义的 `<title>`。
- 全部 CSS 写在 `<style>` 标签内，全部 JS 写在 `<script>` 标签内；不得拆分到外部文件。
- 图标使用 Unicode 字符或内联 `<svg>`；不得引用图标字体或图片文件。
- Mock 数据以 JS 对象/数组形式写在 `<script>` 中，字段与业务场景一致（见第 3 节）。
- 双击 HTML 即可在本地浏览器打开并操作，不依赖本地服务器、不发起网络请求。

## 2. 外部资源硬禁令（含 CSS 中的隐蔽外链）

完全离线是硬约束，以下写法一律禁止，出现即视为不合格：

- CDN 链接、`<link rel="stylesheet" href="...">`、`<script src="...">`。
- 外部字体（`@font-face` 指向远程字体）、外部图片 URL（`<img src="http...">` 或 CSS 背景图远程地址）。
- 任何 `http://`、`https://`、`//` 开头的 `href` 或 `src`。
- CSS 文本中的隐蔽外链同样禁止：`url(https://...)`、`url(http://...)`、`url(//...)` 以及 `@import url(...)`、`@import "..."`；`background-image` 等属性不得引用远程资源。
- 确需图片效果时用内联 SVG 或 CSS 绘制；确需字体时使用系统字体栈（如 `system-ui, sans-serif`），不下载字体文件。

## 3. Mock 数据规范

- 每个实体集合声明为 `const MOCK_<实体名复数> = [...];`，例如 `const MOCK_USERS = [...]`、`const MOCK_ORDERS = [...]`，命名全大写、复数、下划线分隔。
- 字段名、类型与示例值必须与 `_原型说明.md`"数据字典与 Mock 数据约定"节完全一致；状态字段使用其中定义的状态枚举。
- 示例值贴近真实业务（合理姓名、日期、金额、编号），不用 `test`、`foo`、`123` 等无意义占位内容。
- Mock 数据是页面唯一数据源：新增/编辑/删除只改内存中的这些数组，不做持久化。

## 4. 七类交互最小实现要求

每类交互都必须在对应 HTML 中有可运行实现与可识别标记（标记要求见第 5 节）：

1. **导航**：单页模式用菜单/标签切换视图（隐藏非当前视图、显示目标视图）；多页模式用真实 `<a href>` 跳转到存在的 HTML，`index.html` 可达所有页面。
2. **弹窗（modal）**：新增/编辑用 modal；提供打开按钮与关闭方式（关闭按钮、取消、遮罩点击），打开时填入对应数据，编辑态回显已有值。
3. **表格筛选＋重置**：提供筛选条件输入与"筛选"按钮，按条件过滤表格行；"重置"按钮清空条件并恢复完整列表，两按钮均真实生效。
4. **表单必填校验**：提交时对必填字段校验，为空则阻止提交并在字段旁给出提示；校验通过后执行提交逻辑。
5. **状态切换**：状态标签/按钮可切换（如"待处理 → 已通过"），切换后同步更新内存数据与界面显示。
6. **列表增改删联动**：新增、编辑、删除真实修改 `MOCK_*` 内存数组，并立即重新渲染表格/列表，结果与数据一致。
7. **提交 toast**：提交、删除等成功操作后弹出短暂成功提示（toast），自动消失，不阻塞操作。

## 5. 校验器交互标记

为保证生成的 HTML 能通过校验器，页面须出现下列可识别标记（大小写不敏感的文本或属性均可）：

- `MOCK_`：Mock 数据标识（如 `const MOCK_USERS`）。
- `modal`：弹窗相关的类名/id/文案。
- `filter` 或 `resetFilter`：筛选/重置相关标识。
- `toast`：提交反馈相关标识。
- `required`：表单必填属性或等价校验标识。
- 每个 HTML 都须同时具备以上标记，缺失任一会被校验器判为错误。

## 6. 移动端（`app/`）额外约束

- 页面内容固定在 375px 宽度的"手机壳"容器中并水平居中，模拟手机视口；仍满足全部离线约束。
- 底部提供 Tab 栏导航，点击切换视图或页面，功能与前台/后台菜单等价。
- 列表用卡片式布局替代宽表格，卡片内展示关键字段与操作入口。
- 表单、弹窗、toast、状态切换在移动端同样可用，双击 HTML 可直接查看与操作。
