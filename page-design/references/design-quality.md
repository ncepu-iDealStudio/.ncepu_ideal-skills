# Design Quality（设计质量纪律）

设计包决定"长什么样"，本章决定"别做得烂"。生成全程与设计包并行生效；冲突时视觉令牌服从设计包，质量纪律永远生效。

## 反 AI 味（anti-slop）

以下是被视为"AI 生成网站"的高频特征，禁止出现：

1. **Inter 一把梭**：全站只用 Inter/Roboto/Arial/system-ui 而设计包明明指定了其他字体
2. **紫蓝渐变默认症**：`#3B82F6 → #A855F7` 紫蓝渐变用在非 Aurora 类设计包上
3. **卡片套卡片**：card 嵌 card，每块内容都包一层圆角白卡
4. **彩底灰字**：深色/彩色背景上放低对比灰字（对比度不足 4.5:1）
5. **标题上的圆角方块图标**：每个标题左上角一个渐变圆角小方块图标
6. **装饰性滚动字幕/状态条**：普通页面上加 synth-sci-fi 风格的状态滚动条
7. **unicode 字符当图标**：`▣ 仪表盘` `◊ 导航`——要么真实图标（内联 SVG，aria-hidden），要么不用
8. **弹跳缓动**：bounce/elastic easing（观感过时）；默认 ease 或设计包指定的 easing

## 版式与层级

- 正文行宽上限 ~70ch（中文 ~38 字）；行高 1.6–1.8
- 间距用统一节奏（4/8px 网格），禁止随手魔数；token 定义在 base.css `:root`
- heading 视觉层级必须拉开（大小/字重差异明显），不得全靠加粗
- 留白是结构元素，不是浪费；信息密度服从设计包的 density
- 图片必须有明确的 image_treatment（按设计包），禁止随机混用圆角/方角

## 响应式

- 移动优先：单栏起步，断点向上扩展（建议 640 / 1024 / 1320px，可按设计包调整）
- 导航在移动端必须可用（原生 details 方案或登记的 JS 方案）
- 触控目标 ≥ 44×44px；禁用 hover-only 交互
- 文字不得溢出容器；长词/URL 用 `overflow-wrap: break-word`

## 内容纪律

- 每个屏幕上的字符串要么是需求里的真实信息，要么是**知道自己身份的样例内容**；禁止无信息量的填充标签（"赋能未来""极致体验"堆砌）
- 标准 UI 动作用标准文案：按钮就叫"下一步/提交/搜索"，不要主题化改写成"启航认证"
- 样例数据要自然真实，但不得伪装成可当真的真实机构新闻
- **禁止伪造遥测/实时状态**：营销型页面上不得出现"产线状态 运行 满负荷 100%"这类伪装成真实运行数据的面板——那是控制台 UI；即便控制台型页面也必须标注样例
- **禁止代码注释式 kicker**：`// 产品矩阵`、`// INTELLIGENCE LAYER` 这类假装代码注释的小字标签一律删除
- **禁止 mono 大写填充副标题**：`SECURE OPERATOR AUTHENTICATION` 这类无人要求的装饰性副标题一律删除
- 判断填充物的标准：删掉这个字符串，页面不损失任何信息 → 它就是填充物，删掉

## 完成前自查清单

- [ ] 与选定设计包逐项对照：颜色/字体/圆角/阴影/纹理是否全部在包的允许范围内（token 漂移 = 设计包没守住）
- [ ] 首页在 1440px 与 390px 宽度下布局正常、无横向滚动
- [ ] 对比度抽检：正文与背景 ≥ 4.5:1
- [ ] 每页 title 与 h1 是否各司其职
- [ ] 是否存在本清单禁止的 8 项 AI 味特征
