# 教学 PPTX 生成

输入一个教学知识点，先审逐页提纲；确认后再生成带演讲者备注的 **16:9、可编辑 `.pptx`**。本技能不依赖其他技能、Office COM 或在线制片服务。教师确认是出片前的必经步骤。

## 安装与使用

1. 在 WorkBuddy 等支持技能目录的工具中导入完整 `teaching-pptx/`，保留 `scripts/` 和依赖清单。执行阶段需要宿主能读取技能资源、运行 Python、写入工作区。
2. 对助手说：`用 teaching-pptx 为“二分查找”做教学课件。` 可附带授课对象、课时和输出目录，也可以只给名称。
3. 审阅助手给出的逐页提纲，回复 `确认按这个提纲生成 PPTX`，或提出修改。确认前不会创建文件。
4. 确认后，助手使用 Python 3.9+ 和 `python-pptx` 生成文件，默认写入工作区的 `教学课件/`。没有终端或 Python 时，可以完成提纲，但不能通过本包出片。

## 出片脚本与输入规格

若当前 Python 环境缺依赖，可在获得允许后执行：

```sh
python -m pip install -r "技能目录/requirements.txt"
```

确认提纲后，由助手准备 UTF-8 JSON，再执行以下命令（替换为实际路径；若环境使用 `python3` 或独立虚拟环境，调用相应解释器）：

```sh
python "技能目录/scripts/build_pptx.py" "工作区/课件规格.json" "工作区/教学课件/二分查找.pptx"
```

最小规格示例（只演示字段，不代表完整课堂提纲）：

```json
{
  "title": "二分查找",
  "subtitle": "算法入门 · 在有序数组中找目标值",
  "cover_notes": "先问：找字典里的一个词，为什么不用从头翻？",
  "audience": "具备数组基础的编程初学者",
  "learning_objectives": [
    "能说明二分查找适用的数据条件",
    "能手工完成一次二分查找过程"
  ],
  "duration_minutes": 20,
  "slides": [
    {
      "title": "下一步查哪一半？",
      "label": "随堂练习",
      "layout": "practice",
      "points": ["第一次比较后，哪些元素可以排除？", "在 [1, 3, 5, 7, 9] 中查找 9。"],
      "activity": "学生独立判断 1 分钟，再与同桌核对排除范围。",
      "notes": "让学生先独立作答。\n参考答案：中间值为 5，排除 1、3、5，继续查 [7, 9]。"
    }
  ]
}
```

- 封面由顶层字段自动生成，**不必在 `slides` 中再写一次封面**。其余数组元素按顺序出片。
- 新规格必须同时提供：非空单行 `audience`、含 2–3 条非空单行文字的 `learning_objectives`、正整数 `duration_minutes`，以及每个教学页的非空 `activity`。`activity` 可多行，用于保存该页课堂活动或预计用时。
- 为兼容已有输入，三个顶层新字段全部缺失且所有页面均无 `activity` 时，脚本按历史规格生成；只提供部分新字段或部分页面活动会被拒绝。助手新建规格时应始终使用完整新格式。
- `title`、`subtitle`、`label`、每条 `points` 都是非空单行文字。教师提示、衔接语和答案放 `notes`，备注可多行。
- 为减少溢出，脚本按字符宽度做预检：封面标题 34、副标题 68、正文标题 46、栏目 20 单位；每条正文的限额见下表。汉字一般计 2 单位。实际字体排版仍需预览。
- 脚本把受众、学习目标和课时作为版本化 JSON 块附在封面演讲者备注末尾，把每页 `activity` 附在对应页备注末尾；原 `cover_notes` 和 `notes` 内容保持不变，结构化数据不会显示在正文中。旧规格不写入空元数据块。
- 脚本不会覆盖已存在的文件。写出前会用 `python-pptx` 重新读取课件，核对页数、标题、人工备注及结构化教学元数据；此检查不等同于 PowerPoint 的视觉预览。文字和色块均可编辑；本版不自动嵌入图片、动画或复杂公式对象。

## 原创教学版式

视觉设计参考 [Gorden 的原创设计模式](../../ppt/gorden-ppt-skill/references/original-design-guide.md)（留白、统一字号层级、按内容选版式）。本技能没有复制其模板或脚本，也不依赖该技能。页面采用深色文字和单一青色强调，中文指定微软雅黑、拉丁文字指定 Arial；未安装时，实际效果取决于查看器的替代字体。

| `layout` | 用途 | `points` 条数 / 每条宽度上限 |
| --- | --- | --- |
| `bullets`（默认） | 学习目标、并列要点、小结 | 1–4 / 64 |
| `focus` | 居中突出一句定义或结论 | 1 / 60 |
| `compare` | 两栏并排对照，每条应自带对象名 | 2 / 56 |
| `steps` | 用编号演示操作、推导或解题步骤 | 2–4 / 60 |
| `practice` | 第一条是课堂问题，其余是条件或提示 | 1–3 / 60 |

## 建议在独立项目中验收

先只给知识点，确认助手仅回复逐页提纲；给出修改意见，确认助手再次等待确认；明确确认后，检查实际 `.pptx` 能否打开、页序是否和提纲一致、参考答案是否只出现在演讲者备注、未出现在练习页正文。还应回读备注中的结构化块，确认封面可恢复受众、2–3 条学习目标和课时，每个教学页可恢复对应活动，且人工备注内容不变。备注会随 `.pptx` 一起保存；若要把文件发给学生，应另存不含答案备注的版本。最后检查中文字体、换行和练习页的投屏可读性。没有视觉预览时，交付说明应明确标注。
