# 备课辅助助手（lesson-prep-assistant）

面向**计算机专业教师**的备课技能：给一个知识点和教学目标，先出提纲让你把关，确认后生成一套学生能在 VSCode 里打开自学的 Markdown 教材包。

- 技能入口：[SKILL.md](SKILL.md)
- 原创技能，本仓库自研，可自由使用与改造。

## 它解决什么问题

备课写讲义时常见的痛点：

- 一上来就写全文，方向错了要全部返工
- 讲义写成 PPT 式的要点罗列，学生看不懂、没法自学
- 讲解缺逻辑主线，概念、历史、应用、实操混在一起
- 缺少可运行的示例代码和图解，学生只能干读

本技能用**两阶段门控**和**五段认知逻辑**把这两件事固定下来。

## 核心设计

### 1. 两阶段，中间有硬门控

```text
教师输入知识点 + 教学目标
        ↓
阶段一：生成教学内容提纲（拆解知识点 + 五段要点 + 资源规划）
        ↓
⛔ 停下来，等教师审阅 / 修改 / 确认
        ↓
阶段二：生成讲义 md + 示例代码 + 配图 + 导航 README
```

未经确认不生成正文，这是技能的硬性要求。

### 2. 五段认知逻辑

每个知识点按学生"从零到会用"的顺序讲：

| 顺序 | 段落 | 回答的问题 |
| --- | --- | --- |
| 1 | 是什么 | 这东西大概是个啥？ |
| 2 | 为什么会出现 | 没有它之前有什么痛点？ |
| 3 | 发展历程 | 为什么长成现在这样？ |
| 4 | 应用现状 | 现在用在哪、值不值得学？ |
| 5 | 如何开始使用 | 读完能不能马上动手？ |

### 3. 产物是可自学的材料包

```text
<课程主题>-教学材料/
├── README.md         # 学习路径 + 文件清单
├── outline.md        # 已确认的提纲存档
├── notes/            # 讲义正文，一个知识点一篇
├── examples/         # 配套示例代码，可运行 + 思考题
└── assets/           # Mermaid/SVG 图 + 可选示意图
```

成品是**教材**而非幻灯片：充分展开、通俗易懂、示例可跑、关键处有图解。用 VSCode 打开根目录即可自学（建议装 Mermaid 预览插件看图）。

## 如何使用

1. 在支持 Agent Skills 的工具中加载本技能（把 `education/lesson-prep-assistant/` 放进技能目录），或直接把 `SKILL.md` 交给 AI 阅读后按其流程执行。
2. 告诉 AI：要讲的知识点、教学目标，以及学生基础/篇幅/技术栈（后三项可省，AI 会先问或给出假设）。
3. 收到提纲后审阅，提出修改意见或明确确认。
4. 确认后 AI 生成完整材料包，告诉你在哪个目录，用 VSCode 打开即可。

示例输入：

> 给计算机专业大二学生讲"快速排序"，目标是能自己写出代码并分析复杂度，用 Python，篇幅三篇左右。

## 文件结构

```text
lesson-prep-assistant/
├── SKILL.md                              # 技能入口：概述 + 两阶段工作流 + 风格要求
├── README.md                             # 本导读
└── references/
    ├── workflow-and-structure.md         # 输入澄清、拆解原则、产物目录、导航 README 规范
    ├── cognitive-sequence-guide.md       # 五段认知逻辑逐段写法 + 生动通俗技巧
    ├── templates.md                      # 提纲 / 讲义正文 / 示例说明 三套模板
    └── assets-guide.md                   # 示例代码与配图素材的生成、组织、引用规范
```
