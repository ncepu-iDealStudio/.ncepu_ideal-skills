# education：教育类技能库

本目录集中收录面向 AI 助手的教学技能，覆盖备课、讲义编写、PPT 与互动课件制作、竞赛培训等环节。`lesson-prep-assistant` 和 `teaching-pptx` 由本仓库维护，其他技能的来源与许可见下表。

## 技能总览

| 技能 | 面向对象 | 主要产出 | 一句话定位 |
| --- | --- | --- | --- |
| [`lesson-prep-assistant`](lesson-prep-assistant/) | 高校计算机专业教师 | Markdown 自学讲义 + 示例代码 + 配图 | 先出提纲、教师确认后再生成整套自学材料包 |
| [`teaching-pptx`](teaching-pptx/) | 任课教师与助教 | 可编辑的 16:9 PPTX + 演讲者备注 | 只给知识点即可起步，逐页提纲经教师确认后才出片 |
| [`prepkit`](prepkit/) | 信息学奥赛教练 | 备课思路与质量参照 | 不设固定流程的竞赛备课思考框架 |
| [`TeachAnyHE`](TeachAnyHE/) | 高校教师 / 助教 / 研究生 | 互动课件、仿真、知识图谱等 | 面向本科与研究生课程的互动学习体验开发 |

## 各技能简介

### lesson-prep-assistant

本仓库自行维护的技能。面向高校计算机专业教师，围绕知识点生成**学生可自读的教材式材料包**，而不是投屏用的幻灯片。核心是两段式硬门控：先交付教学内容提纲，教师明确确认后才展开正文、示例代码和配图。讲解按「是什么 → 为什么会出现 → 发展历程 → 应用现状 → 如何开始使用」的内在叙事顺序组织，小节标题按具体内容自拟；示例代码被视作论证链的一环，要求可运行、有输出解读，并诚实标注来源与验证状态。

### teaching-pptx

从教学知识点起步，先在对话中给出逐页提纲和教学活动，教师明确确认后才生成 `.pptx`。可按完整目录导入支持技能目录的 AI 工具；出片阶段需要 Python 和 `python-pptx`，不依赖其他技能。见[安装说明和最小示例](teaching-pptx/README.md)。

### prepkit

面向信息学奥赛（NOI / CSP / GESP）培训的备课引导框架，针对 6 年级竞赛生设计。它不规定「先做什么再做什么」，而是基于 ADDIE 模型提供一组思考维度——目标清晰、引人入胜、主动发现、学练结合、图文并茂、逻辑连贯——帮助判断一堂课的质量，并让 AI 根据内容本身选择表达方式，避免千篇一律的模板。适合作为备课质量的参照系，而非讲义流水线操作手册。

### TeachAnyHE

面向大学本科与研究生课程的高等教育互动课件开发技能，覆盖数学、计算机、通信、电气、自动化等专业。目标是做出有问题锚点、有推导或仿真、有讲解、有评估、有知识体系映射的学习体验，而非把知识堆进页面：可做算法可视化、公式推导、信号与电路仿真、教学动画、AI 助教、TTS 讲解、课程知识图谱、课程设计与实验项目等。它以专业培养方案、课程教学大纲和教材目录为依据，在本地生成课程知识图谱，不依赖外部平台。当前为 2.0.0 版，是 TeachAny 的高等教育改造版，K-12 专属部分已替换为高校对应概念。

## 怎么选

- 要写学生自己读的讲义或自学材料：`lesson-prep-assistant`
- 只有知识点，想先审提纲再生成教学 PPTX：`teaching-pptx`
- 要备信息学奥赛课、需要课堂质量参照：`prepkit`
- 要做大学互动课件、仿真或知识图谱：`TeachAnyHE`
