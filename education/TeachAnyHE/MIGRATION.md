# TeachAny → TeachAnyHE 迁移说明

本文档说明 TeachAnyHE 与 TeachAny 在**功能结构、课程内容组织、示例风格**三个维度上的完整对应关系，以及哪些 K-12 专属内容被保留、改造或删除，并说明设计理由。

**迁移原则**：TeachAny 的内核是一套与学段无关的「教学设计操作系统」——六问、ABT 叙事、认知负荷、Mayer 原则、脚手架、自适应四分支、探究式学习、五镜法、Bloom 评估、学习闭环。这些方法全部保留。与 K-12 强绑定的部分（学段、课标、发布平台、生活化情境、游戏化）全部改造或移除。

---

## 一、功能结构对应关系

| TeachAny（K-12） | TeachAnyHE（高等教育） | 处理 | 理由 |
| --- | --- | --- | --- |
| 六问（学生/先修/目标/场景/难点/验证） | 六问（同名，第 3 问改为对应**毕业要求指标点**） | 保留改造 | 方法通用；HE 需对接 OBE |
| ABT 叙事结构 | ABT 叙事结构（示例换 HE） | 保留 | 叙事方法无学段差异 |
| 内容审计 Essential/Helpful/Decorative | 同名 + 「不得照搬教材目录」硬规则 | 保留加强 | 大学课件最常见的病就是照抄目录 |
| 认知负荷（Sweller） | 同名 + 「推导逐步展开/折叠」对策 | 保留加强 | 数学推导是 HE 特有高负荷场景 |
| Mayer 多媒体原则 | 同名 | 保留 | 通用 |
| 脚手架三级 | 同名（示例换：推导/编程/课程设计） | 保留 | 通用 |
| 自适应四分支 | 同名（先修判定基于 course-graph.json） | 保留改造 | 数据源从课标树换为本地知识图谱 |
| 探究式学习四层 | 同名（探究=实验/课程设计/研讨/科研训练；L4 对应研究生） | 保留改造 | HE 探究形态与 K-12 不同 |
| 课型分类（5 种） | 6 种：新增**课程设计**课型 | 保留扩展 | 课程设计是高校特有课型 |
| 学科适配矩阵 | 专业课程适配矩阵（数学/计算机/通信/电气/自动化/机械/物理/化学/经管，共 9 类） | 改造 | 学科→专业课程群 |
| 五镜法 | 同名（示例换 HE，「讲/迁」侧重定理证明与工程应用） | 保留 | 通用 |
| 评估系统（Bloom） | 同名（理工/经管文科双栏例题） | 保留 | 通用 |
| 先修链 | 同名（前置课程 + 知识点双层） | 保留改造 | HE 先修以「前置课程」为单位 |
| 学段差异（小/初/高） | 层次差异（本科低年级/高年级/研究生） | 替换 | 对象不同 |
| 4-Phase 工作流（含 Phase 0.5 课标检索） | 4-Phase（Phase 0 定位培养方案/大纲；无 Phase 0.5） | 保留改造 | 无课标平台，改为本地产出 |
| Generation Gate / Completeness Gate | 同名（检查项换为公式/图谱/门类/19 项基线） | 保留改造 | 门禁机制通用 |
| 标准模块五件套（AI 学伴/教师卡片/TTS/section hints/知识图谱） | 五件套（AI **助教**/教师卡片/TTS/section hints/课程知识图谱） | 保留改造 | AI 学伴→AI 助教，语气专业化 |
| 前端学习闭环（teachany_ 命名空间） | 前端学习闭环（teachanyhe_ 命名空间） | 保留改名 | 避免与 K-12 课件数据冲突 |
| 游戏化成就（徽章/连击/emoji） | **学术里程碑**（章节完成度/掌握度/连续学习/综合任务） | 改造 | 大学生对游戏化激励不敏感，需克制 |
| PWA 离线 | 同名 | 保留 | 通用 |
| 课标 node_id + GitHub 知识树 + hang_tree.py | 培养方案 + 教学大纲 + 本地 `course-graph.json` | **替换** | HE 无统一课标，无 teachany.cn 平台 |
| teachany.cn 发布闭环 | 本地 HTML 交付 + 可选导出（PDF/PPTX/LaTeX/LMS） | **替换** | 高校教师交付场景是本地/ LMS |
| 互动引擎（function/circuit/equilibrium，生活化实验） | 函数图像/信号频谱/电路仿真/算法可视化引擎 | 改造 | 生活化→工程科研情境 |
| 动画工具（Manim/Motion Canvas/PhET） | Manim/Motion Canvas/内置 JS 仿真（删 PhET） | 保留改造 | PhET 为 K-12 生活实验 |
| 历史地图/地形 3D/疆域整合 | — | **删除** | 史地专属，HE 专业课程用不到 |
| 年级视觉模式（小学糖果/初中蓝绿/高中深蓝） | 学科门类视觉（理科深蓝/工科浅灰/经管米白） | 替换 | 视觉驱动变量从学段变为学科门类 |
| —（K-12 无） | **KaTeX 公式渲染强制** + `.derivation` 推导组件 | **新增** | 数学严谨表达是 HE 核心需求 |
| —（K-12 无） | **算法/代码可视化强制** + 复杂度对比 | **新增** | 计算机类课程核心需求 |
| —（K-12 无） | **OBE 目标映射**（graduate_attr 毕业要求指标点） | **新增** | 工程教育认证/一流课程建设要求 |
| —（K-12 无） | **AI 助教学术诚信边界**（不代做课程设计/论文） | **新增** | HE 特有学术规范 |

## 二、课程内容组织对应关系

| 维度 | TeachAny（K-12） | TeachAnyHE（高等教育） |
| --- | --- | --- |
| 知识层级 | 学段 → 学科 → 单元 → 知识点 | 专业 → 课程 → 章节 → 知识点 |
| 知识定位依据 | 国家课程标准 node_id | 专业培养方案 → 课程教学大纲 → 教材目录 |
| 目标框架 | 课标要求 + 学段目标 | OBE：知识点 → 课程目标 → 毕业要求指标点 |
| 学生分层 | 小学/初中/高中 | 本科低年级/本科高年级/研究生 |
| 知识图谱存储 | GitHub 仓库统一挂树 | 每课件本地 `course-graph.json`（含 prerequisites/leads_to/bloom_verbs/graduate_attr） |
| 先修链 | 跨年级知识点链 | 前置课程（如「复变函数→信号与系统」）+ 知识点双层 |
| 模块节奏 | 小学 5-10 分钟/模块 | 低年级 10-15、高年级 15-30、研究生至 45 分钟/模块 |
| 页面结构 | 九段结构（引入→概念→建模→例题→练习→小测→总结） | 目标导向结构（目标→前测→模块→综合任务→后测→拓展→知识图谱） |
| 项目形态 | PBL 大项目（校园测量师/桥梁工程师），成果=展览页 | 课程设计/大作业/科研训练，成果=设计报告/代码/仿真/答辩 |
| 考核对接 | 中考/高考题型 | 课程考试 + 考研题型 + 课程设计评分量表（Rubric） |

## 三、示例风格对应关系

| 维度 | TeachAny（K-12） | TeachAnyHE（高等教育） |
| --- | --- | --- |
| 示例覆盖 | 数学（二次函数）、语文、英语、物理、历史等中小学学科 | 数学（最优化方法·梯度下降）、计算机（数据结构·二叉搜索树）、通信（信号与系统·傅里叶变换）、电气（电路分析·RC 暂态） |
| 问题锚点风格 | 生活情境（投篮轨迹、餐厅点餐、溢水杯） | 工程/科研/学科前沿情境（机器学习训练、数据库索引、语音压缩、电源设计） |
| 认知冲突来源 | 生活直觉与科学结论相悖 | 概念/定理的深刻内涵（时域卷积为何变频域相乘） |
| 深度理解终点 | 会做题、会应用 | 会推导证明、会复杂度分析、会设计系统、会批判性评价 |
| 视觉语言 | 糖果色/渐变色/emoji/游戏化动效 | 学科门类三色（理科深蓝学术/工科浅灰工程/经管米白典雅），克制、无 emoji 弹窗 |
| 表达介质 | 图文卡片 + 简单动画 | KaTeX 公式 + 分步推导 + 算法可视化 + 波形/电路仿真 + 参考文献 |
| 练习题型 | 选择/填空/拖拽为主 | 客观 50% + 解释 30% + 产出 20%（证明/编程/设计/建模/报告） |
| AI 角色语气 | 学伴（陪伴、鼓励、游戏化） | 助教（答疑、推导提示、文献推荐、守学术诚信） |

## 五、版本与边界

- TeachAnyHE v1.0.0 迁移自 TeachAny v7.21.0 框架（以 `TeachAny.md` 单文件版为准）。
- **适用边界**：大学本科/研究生课程的互动课件。K-12 仍用 `teachany`，企业培训不适用。
- **不迁移清单（明确不做）**：teachany.cn 发布、GitHub 挂树脚本、课标 node_id、历史地图/地形 3D、PhET 生活实验、游戏化成就系统。
