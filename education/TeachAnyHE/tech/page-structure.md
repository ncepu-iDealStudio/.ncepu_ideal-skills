# 页面结构与前端学习闭环（高等教育版）

> **所属**：TeachAnyHE 技能 · 卫星文档
> **触发时机**：Phase 3 构建页面、接线前端逻辑时
> **主文档**：[../SKILL.md](../SKILL.md)
>
> 对应 TeachAny 的 `tech/page-structure.md`。页面结构从 K-12 九段结构升级为高等教育「目标导向 + 公式/算法/仿真」结构；前端学习闭环命名空间由 `teachany_` 改为 `teachanyhe_`。

---

## 一、标准页面结构

```text
Hero 区（课程标题 + 专业/课程/课型标签 + 核心问题 + 知识结构图）
导航（锚点）
课程目标（含毕业要求指标点 graduate-attr）
前测（先修诊断）
知识模块 × N
  ├─ ABT 导入
  ├─ 核心讲解（定义/定理 + 公式 KaTeX 渲染 + 直观说明）
  ├─ 深度理解（五镜法）
  ├─ 互动/仿真（参数滑块 / 推导 / 算法可视化 / 电路仿真）
  ├─ 即时练习（带反馈）
  └─ 错误诊断
综合任务（含脚手架层级）
后测
拓展资源（前沿/文献/进阶）
课程知识图谱（course-graph.json 渲染）
```

## 二、标准模块接线（五件套）

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| **AI 助教** | 左下角悬浮 | 语气专业，侧重「答疑/推导提示/文献推荐」 |
| **教师卡片** | Hero 下方或末尾 | 授课教师/助教信息 + 联系方式 |
| **TTS 讲解** | 右下角悬浮控制器 | 连续播放 + 段落高亮 |
| **section hints** | 每节开头 | 分节提示（本节目标 + 前置回顾） |
| **课程知识图谱** | 末尾 | 基于 course-graph.json 渲染先修/后继/Bloom |

## 三、CSS 与视觉

学科门类视觉令牌见 `tech/design-system.md`。关键约束：

- `body` 用 `teachanyhe-science` / `teachanyhe-engineering` / `teachanyhe-econ`

## 四、前端学习闭环系统（零后端）

`localStorage` + 原生 JS，无账号无服务器，单文件自包含。命名空间 `teachanyhe_`。

### 五大子系统

1. **自适应分支**：`TeachAnyHEAdaptive.decideBranch()`（四分支，见主文档 1.7）
2. **进度持久化**：模块完成、滚动位置、答题记录、掌握度
3. **间隔重复**：简化 SM-2 算法，复习知识点（键 `teachanyhe_review`）
4. **学术里程碑**：章节完成度/掌握度/连续学习天数/综合任务完成（克制、无 emoji 弹窗）
5. **PWA 离线**：manifest + service worker

### 关键存储键

| 数据 | 存储键 |
| --- | --- |
| 模块完成 | `teachanyhe_progress_{courseId}` |
| 掌握度 | `teachanyhe_mastery` |
| 复习队列 | `teachanyhe_review` |
| 里程碑 | `teachanyhe_milestones` |

### 边界与降级（前端健壮性）

- **localStorage 被禁**（隐私模式/浏览器策略）：所有读写包 `try/catch`，失败时回退到内存对象，功能不崩、给出「进度不会保存」提示。
- **`file://` 下 fetch 受限**：`course-graph.json` 加载失败时，降级为静态「知识点清单」列表，不白屏。
- **Canvas/SVG 不支持**（极老浏览器）：互动区静默跳过绘制、保留上方文字说明，不报错。
- **KaTeX CDN 不可达**：检测 `renderMathInElement`（或 `window.katex`）未定义时，公式保留 LaTeX 源码原文显示，并在页面顶部插入可见提示条「公式渲染库未加载（离线环境请改用本地 ./assets/katex/）」；不做 Unicode 自动转换（不冒充转换能力）。

## 五、AI 助教（高等教育语气）

AI 助教在高等教育中侧重**专业答疑与引导**，而非 K-12 的「学伴陪聊」：

- 学生问「这一步为什么能交换求和与极限」→ 给出严谨依据（一致收敛/控制收敛等前提）
- 学生问「这个算法适合我的问题吗」→ 引导分析适用条件，而非直接给答案
- 学生问「推荐文献」→ 给出方向性文献建议，标注「请自行核对最新版本」

**硬规则**：AI 助教不替学生做课程设计/大作业/论文的核心推导与撰写，只做提示与方向引导（学术诚信）。

**实现方案（三选一，按可用资源降级）**：

1. **外部大模型 API**：调用用户已配置的 LLM 接口（OpenAI / 通义 / DeepSeek 等兼容 API），凭据从环境变量读取，禁止在课件源码硬编码 Key；前端通过 `fetch` 调用本地/远端代理。
2. **本地规则式**（无 API 凭据）：预设「概念卡 + 常见问题 FAQ + 错因诊断」的规则问答，覆盖本课高频疑问，无需联网。
3. **静态提示卡**（完全离线）：嵌入「学习提示」卡片引导学生自查，不调用任何模型。

**降级链**：API 可用 → 方案 1；无凭据/无网 → 方案 2；规则卡也未配置 → 方案 3（静态提示卡，且不对外宣称是"AI"）。任何情况都不能因 AI 助教不可用而阻断课件交付。

## 六、与 TeachAny 的对应

| TeachAny | TeachAnyHE |
| --- | --- |
| 九段结构（引入→概念→建模→例题→练习→小测→总结） | 目标导向结构（目标→前测→模块→综合任务→后测→拓展） |
| AI 学伴（陪聊/游戏化） | AI 助教（专业答疑/推导提示/文献推荐） |
| 知识图谱（挂树 path.html/tree.html） | 课程知识图谱（本地 course-graph.json） |
| `teachany_` 命名空间 | `teachanyhe_` 命名空间 |
| 游戏化成就（徽章/连击） | 学术里程碑（章节完成/掌握度/连续学习） |
