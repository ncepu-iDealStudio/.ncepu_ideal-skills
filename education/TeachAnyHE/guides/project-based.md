# 项目制、课程设计与任务驱动（高等教育版）

> **所属**：TeachAnyHE 技能 · 卫星文档
> **触发时机**：做课程设计 / 大作业 / 项目制 / 研讨式课件时
> **主文档**：[../SKILL.md](../SKILL.md)
>
> 对应 TeachAny 的 `guides/project-based.md`。高等教育中的「项目」体现为：课程设计、大作业、综合实验、科研训练、研讨课。

---

## 一、推荐引入顺序（通用）

```text
真实任务 / 现象 / 问题 → 学生尝试 → 暴露不足 → 引入新知识 → 立即应用
```

## 二、问题驱动设计

1 个**核心问题** → 3-4 个**子问题**，形成递进式问题链：

```text
核心问题：为什么梯度下降在深度学习里几乎总是有效的？
├── 子问题1：梯度方向与函数下降有什么关系？（记忆/理解）
├── 子问题2：学习率（步长）如何影响收敛？（应用/分析）
├── 子问题3：为什么不同问题要选不同优化器（SGD/Adam）？（分析/评价）
└── 子问题4：针对一个具体损失函数，设计并验证一个改进方案（评价/创造）
```

**设计原则**：子问题逻辑递进（是什么→为什么→怎么样→怎么办），对应 Bloom 层级（L1 记忆理解 → L2 应用分析 → L3 评价创造 → L4 综合迁移）。

## 三、课程设计/大作业驱动设计

1 个**大项目** → 3-5 个**子阶段**，产出完整作品：

```text
课程设计：设计一个低通滤波器（《信号与系统》/《数字信号处理》）
├── 阶段1：需求分析 — 明确截止频率、阻带衰减等指标（输入）
├── 阶段2：方案设计 — 选择滤波器类型与阶数，推导传递函数（加工）
├── 阶段3：实现 — 代码/仿真实现，绘制幅频/相频响应（输出初稿）
├── 阶段4：测试 — 用测试信号验证性能指标（验证）
└── 阶段5：报告 — 撰写设计报告 + 答辩展示（最终成果）
```

**设计原则**：
- 大项目必须有明确**最终成果物**（设计报告、代码、仿真结果、方案、答辩）
- 每个阶段有独立**子成果**（阶段交付物）
- 阶段间体现「输入 → 加工 → 输出 → 验证」的工程/科研递进
- 每个阶段对应一个可提交的互动模块

**各专业课程设计示例**：

| 课程 | 项目名称 | 最终成果物 |
|:---|:---|:---|
| 数据结构 | 设计并实现一个支持区间查询的平衡树 | 代码 + 复杂度分析报告 |
| 信号与系统 | 设计一个满足给定指标的滤波器 | 设计报告 + 仿真响应 |
| 电路分析 | 设计一个 DC-DC 稳压电源 | 电路方案 + 仿真波形 |
| 自动控制原理 | 设计一个倒立摆的稳定控制器 | 控制器 + 阶跃响应仿真 |
| 最优化方法 | 用梯度类算法求解一个实际优化问题 | 建模 + 求解 + 收敛性分析 |
| 计量经济学 | 用回归模型分析一组真实数据 | 建模报告 + 实证结论 |

## 四、科研训练驱动（研究生/高年级）

研究生/科研训练类课件用「问题 → 文献 → 方法 → 复现/改进 → 汇报」：

```text
科研任务：复现并改进某篇论文的方法
├── 阶段1：读文献 — 理解问题设定与核心方法（输入）
├── 阶段2：复现 — 复现基准结果（加工）
├── 阶段3：改进 — 提出一个改进点并验证（创新）
└── 阶段4：汇报 — 撰写报告 + 同行评议（输出）
```

## 五、问题链驱动设计

环环相扣的问题链，驱动思维从记忆到创造：

```text
Level 1（记忆/理解）：XX 是什么？ → 建立基本认知
Level 2（应用/分析）：为什么是这样？ → 深入理解原理
Level 3（分析/评价）：有什么影响/区别？ → 多角度分析
Level 4（评价/创造）：如果是你，怎么做？ → 迁移创造
```

**与五镜法结合**：Level 1 用「看+拆」，Level 2 用「讲+比」，Level 3 用「比+迁」，Level 4 用「迁+创造」。

## 六、跨章节/跨课程融合设计

高等教育专业课常需综合多章知识：

| 融合类型 | 说明 | 课件实现方式 |
|:---|:---|:---|
| **知识关联型** | 借用前置课程知识辅助理解 | 相关知识点旁加「先修回顾」卡片 |
| **方法迁移型** | 一个课程的方法用于另一课程 | 设置「方法迁移挑战」互动任务 |
| **主题统整型** | 围绕一个主题融合多章 | 多视角分析模块（每章一个标签页） |
| **项目综合型** | 一个项目需多章/多课知识完成 | 项目阶段标注「本阶段所需先修知识」 |

## 七、各专业课程任务引入示例

- 数学（最优化方法）：如何用最小二乘拟合一组带噪声的测量数据？
- 计算机（数据结构）：如何设计一个能在千万级数据里毫秒级查找的结构？
- 通信（信号与系统）：如何把一段语音信号压缩到原来 1/10 还能听清？
- 电气（电路分析）：如何设计一个能把 220V 交流稳定成 5V 直流的电源？
- 自动化（自动控制原理）：如何让一个倒立摆不倒下？
- 经管（计量经济学）：给定历史收益，如何构造风险最小的投资组合？
