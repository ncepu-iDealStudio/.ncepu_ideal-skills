## 示例 A：数学类 —「梯度下降法」（《最优化方法》）

**六问**：

1. 大三数学/计算机本科生，已学微积分、线性代数
2. 先修：方向导数、梯度、矩阵运算、泰勒展开
3. 学完能做：推导梯度下降迭代公式，说明步长与收敛性关系
4. 真实场景：机器学习训练中的参数优化
5. 常见错误：混淆梯度方向与下降方向、步长选择不当
6. 成功标准：能独立推导迭代公式并判断某步长下是否收敛

**课件结构**：

- ABT 导入：「你会求显式函数极值（And），但损失函数无法求闭式解（But），所以要迭代下降（Therefore）」
- 深度理解：**看**（等高线下降动画）→ **拆**（方向导数一阶展开）→ **迁**（最速下降方向 = 负梯度）
- 互动：Canvas 等高线 + 参数滑块（步长 α 调大调小观察震荡/收敛/发散）
- 练习：基础（写出迭代公式）→ 应用（给定函数与起点手算 3 步）→ 迁移（分析步长过大为何发散）
- 错误诊断：「沿梯度方向走」→「梯度是上升最快方向，应沿负梯度」

## 示例 B：计算机类 —「二叉搜索树与平衡」（《数据结构》）

**六问**：

1. 大二计算机本科生，已学线性表、栈、队列
2. 先修：线性表、递归、指针
3. 学完能做：构造/插入/删除/查找二叉搜索树，分析平均与最坏复杂度
4. 真实场景：数据库索引、符号表的高效查找
5. 常见错误：删除结点时丢失子树、忽略退化成链表的退化情况
6. 成功标准：能画出给定序列的插入过程并分析退化情况

**课件结构**：

- ABT 导入：「你会顺序表和链表（And），但海量数据插入删除效率低（But），所以要树形结构（Therefore）」
- 深度理解：**看**（插入动画）→ **比**（顺序查找 vs 二叉搜索树）→ **讲**（平衡因子与退化）
- 互动：算法可视化（逐步插入/查找/删除，结点高亮），复杂度对比表
- 练习：基础（画出插入序列结果）→ 应用（删除含两子树的结点）→ 迁移（分析有序序列插入为何退化为链表）
- 错误诊断：「删除后直接删结点」→「需用后继结点替换并递归删除」

## 示例 C：通信类 —「傅里叶变换的频谱含义」（《信号与系统》）

**六问**：

1. 大三通信/电子信息本科生，已学电路分析、高等数学、复变函数
2. 先修：正弦稳态分析、复数、积分
3. 学完能做：解释时域信号与频域频谱的对应关系，用频谱分析信号带宽
4. 真实场景：语音/图像信号的频域处理、滤波器设计
5. 常见错误：混淆周期信号（离散谱）与非周期信号（连续谱）、忽略负频率
6. 成功标准：能由时域波形大致判断频谱形状并说明带宽

**课件结构**：

- ABT 导入：「你会分析正弦稳态（And），但真实信号是非周期的（But），所以要傅里叶变换（Therefore）」
- 深度理解：**看**（时域波形 ↔ 频谱双视图动画）→ **讲**（傅里叶变换物理意义）→ **迁**（带宽概念）
- 互动：Canvas 波形/频谱双视图 + 参数滑块（改变信号时长/幅度观察频谱变化）
- 练习：基础（写出常见信号傅里叶变换）→ 应用（由频谱反推时域特征）→ 迁移（分析采样与带宽关系）
- 错误诊断：「周期信号也是连续谱」→「周期信号对应离散谱（傅里叶级数）」

## 示例 D：电气类 —「RC 电路的暂态响应」（《电路分析》）

**六问**：

1. 大二电气/自动化本科生，已学电路基本定律
2. 先修：基尔霍夫定律、一阶微分方程
3. 学完能做：求解 RC 电路暂态响应，说明时间常数的物理意义
4. 真实场景：电子设备上电时序、滤波电路
5. 常见错误：混淆时间常数、忘记初始条件
6. 成功标准：能推导 RC 充电/放电表达式并画出波形

**课件结构**：

- ABT 导入：「你会纯电阻电路（And），但含电容的电路不能突变（But），所以要暂态分析（Therefore）」
- 深度理解：**看**（RC 充放电波形动画）→ **讲**（储能元件特性）→ **比**（电容 vs 电感）
- 互动：电路仿真（改变 R/C 参数观察时间常数变化，波形实时更新）
- 练习：基础（写出时间常数）→ 应用（求某时刻电压）→ 迁移（设计满足给定时间常数的电路）
- 错误诊断：「电容电压立即跟随」→「电容电压不能突变，按指数趋近」

## 示例 E：自动化类 —「PID 控制与稳定性」（《自动控制原理》）

**六问**：

1. 大三自动化/电气本科生，已学电路、微分方程、拉普拉斯变换
2. 先修：传递函数、拉普拉斯变换、负反馈概念
3. 学完能做：搭建 PID 控制器，说明 P/I/D 各项对阶跃响应（超调/稳态误差/响应速度）的影响
4. 真实场景：无人机姿态控制、电机调速、温度控制
5. 常见错误：混淆 P/I/D 各自作用、忽略积分饱和、误判稳定性
6. 成功标准：能调 PID 参数使系统满足给定超调量与调节时间

**课件结构**：

- ABT 导入：「你会开环控制（And），但扰动与误差会累积不消（But），所以要负反馈 + PID（Therefore）」
- 深度理解：**看**（阶跃响应曲线）→ **拆**（P/I/D 各自作用）→ **比**（不同参数组合的响应对比）
- 互动：控制系统仿真（调节 Kp/Ki/Kd 滑块，实时看阶跃响应与稳定性）
- 练习：基础（写出 PID 传递函数）→ 应用（给定系统调参数）→ 迁移（分析积分饱和与抗饱和）
- 错误诊断：「P 越大响应越快越好」→「P 过大引发超调与振荡」

## 示例 F：机械类 —「机构运动与自由度」（《机械原理》）

**六问**：

1. 大二机械本科生，已学理论力学
2. 先修：平面运动学、矢量分析
3. 学完能做：计算平面机构自由度，判断机构运动是否确定
4. 真实场景：机械臂、发动机曲柄连杆、机器人关节
5. 常见错误：漏数虚约束/复合铰链、局部自由度判断错误
6. 成功标准：能正确计算给定机构的自由度并判断运动确定性

**课件结构**：

- ABT 导入：「你会分析单个刚体运动（And），但多构件联动是否可动需要判断（But），所以要自由度分析（Therefore）」
- 深度理解：**看**（机构运动动画）→ **拆**（构件/运动副分解）→ **迁**（自由度公式应用）
- 互动：机构运动仿真（拖动构件观察运动，参数化改变杆长）
- 练习：基础（识别运动副类型）→ 应用（计算四杆机构自由度）→ 迁移（判断含复合铰链机构的自由度）
- 错误诊断：「虚约束也计入自由度」→「虚约束需去除后再计算」

## 示例 G：化学类 —「化学平衡与勒夏特列原理」（《物理化学》）

**六问**：

1. 大二化学/化工本科生，已学无机化学、热力学基础
2. 先修：反应速率、平衡常数、热力学函数
3. 学完能做：用勒夏特列原理预测条件改变时平衡移动方向，定量计算平衡组成
4. 真实场景：合成氨工业、化工生产条件优化
5. 常见错误：混淆浓度/压强/温度对平衡的不同影响、忽略催化剂不影响平衡
6. 成功标准：能预测并解释条件改变对平衡的影响

**课件结构**：

- ABT 导入：「你会计算单向反应的转化（And），但可逆反应存在动态平衡（But），所以要平衡常数与勒夏特列原理（Therefore）」
- 深度理解：**看**（反应进程曲线）→ **讲**（平衡常数含义）→ **迁**（合成氨条件优化）
- 互动：反应仿真（调节浓度/压强/温度，观察平衡移动方向）
- 练习：基础（写出平衡常数表达式）→ 应用（计算平衡组成）→ 迁移（分析工业条件选择）
- 错误诊断：「催化剂提高转化率」→「催化剂只加速平衡到达，不改变平衡位置」

## 示例 H：物理类 —「麦克斯韦方程组与电磁波」（《电动力学》）

**六问**：

1. 大二物理/电子信息本科生，已学高等数学、普通物理
2. 先修：矢量分析、偏微分方程、电磁感应
3. 学完能做：写出麦克斯韦方程组，说明电磁波传播与光速的关系
4. 真实场景：无线通信、光通信、电磁兼容
5. 常见错误：混淆位移电流与传导电流、忽略边界条件
6. 成功标准：能由麦克斯韦方程组推导电磁波方程

**课件结构**：

- ABT 导入：「你会库仑定律与电磁感应（And），但变化的电场与磁场如何相互激发（But），所以要麦克斯韦方程组（Therefore）」
- 深度理解：**看**（电磁波传播动画）→ **拆**（四个方程的物理含义）→ **迁**（光速与电磁波）
- 互动：电磁波传播仿真（调节频率/介质观察波长与传播）
- 练习：基础（写出四个方程）→ 应用（由方程推导波动方程）→ 迁移（解释边界条件与反射折射）
- 错误诊断：「位移电流也是电荷流动」→「位移电流是变化的电场，非电荷流动」

## 示例 I：经管类 —「线性规划与影子价格」（《运筹学》）

**六问**：

1. 大三经管/工程管理本科生，已学线性代数、微积分
2. 先修：矩阵运算、约束优化基础
3. 学完能做：建立线性规划模型，用单纯形法求解并解释影子价格
4. 真实场景：生产计划、资源分配、供应链优化
5. 常见错误：混淆目标函数与约束、误读影子价格经济含义
6. 成功标准：能建模求解并解释资源影子价格的经济意义

**课件结构**：

- ABT 导入：「你会单变量极值（And），但多约束资源分配无法解析（But），所以要线性规划（Therefore）」
- 深度理解：**看**（可行域图形）→ **拆**（约束与目标函数）→ **迁**（影子价格与敏感性）
- 互动：线性规划求解器（调节约束参数观察最优解与影子价格变化）
- 练习：基础（建模型）→ 应用（单纯形法求解）→ 迁移（影子价格与资源定价决策）
- 错误诊断：「影子价格就是市场价格」→「影子价格是资源的边际贡献」

## 示例小结：九类课程的共性迁移点

| 维度 | K-12 示例（原） | HE 示例（迁移后） |
| --- | --- | --- |
| 学生对象 | 九年级/八年级/高一 | 大二/大三本科生 |
| 先修 | 平方运算/词汇 | 前置课程 + 知识点（复变函数、线性表等） |
| 真实场景 | 投篮轨迹/餐厅点餐 | 机器学习训练/数据库索引/信号处理/电源时序 |

| 知识组织 | 学段-单元 | 课程-章节-知识点 + 毕业要求指标点 |

## 示例 J：端到端交付实例（傅里叶变换）

以下展示从「一句话需求」到「完整成品」的最小闭环，其余示例（A/B/C/D）均按此收尾，而非停在教学设计层。

**用户输入**：`给大三电子信息本科生讲傅里叶变换，做一个能调参数看时域波形和频谱的页面。`

**Phase 0 六问产出**：
1. 学生：大三电子信息，已学电路分析、高等数学、复变函数
2. 先修：正弦稳态分析、复数、积分
3. 学完能做：解释时域-频域对应关系，用频谱判断信号带宽
4. 场景：语音/图像信号的频域处理、滤波器设计
5. 难点：周期信号（离散谱）vs 非周期信号（连续谱）、忽略负频率
6. 验证：由时域波形判断频谱形状并说明带宽

**交付文件清单**（`fourier-courseware/`）：

```text
fourier-courseware/
├── index.html              # 课件主页面（波形/频谱双视图 + 参数滑块）
├── manifest.json           # 课程/专业/课型/知识点清单
├── course-graph.json       # 知识点先修/后继/Bloom/毕业要求指标点
├── PLAN.md                 # 制作计划 + 19 项基线核对记录
├── assets/                 # 动画/图片（如 spectrum.mp4）
└── tts/                    # ≥3 个讲解 mp3（引言/核心/小结）
```

**交付摘要**：已含 AI 助教（规则问答 + 静态提示卡降级）、连续音频播放器（3 个 mp3）、课程知识图谱三模块；公式经 KaTeX 渲染；`python -m json.tool` 校验通过、浏览器控制台无报错、移动端不崩。未导出 PDF/PPTX（本课为互动仿真，本地 HTML 即最终形态）。

**验收对照**：`references/baseline-rules.md` 19 项基线逐项勾选；质检命令见 `phases/deliverables.md`。
