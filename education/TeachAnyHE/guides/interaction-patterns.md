## 一、通用互动组件

| 组件 | 用途 | 适用课程 |
|:---|:---|:---|
| **前测/后测** | 判断是否形成学习闭环 | 全部 |
| **概念题（ConcepTest）** | 检查是否真正理解，不只是记住 | 全部 |
| **参数调节器** | 观察变量变化带来的结果 | 数学、物理、信号、电路 |
| **逐步推导** | 帮学生建立完整过程感（公式推导/证明） | 数学、信号、电路、物理 |
| **公式渲染** | 专业级公式呈现（KaTeX） | 数学/物理/信号/电路 |
| **算法可视化** | 逐步观察算法执行过程 | 计算机 |
| **代码执行** | 运行并观察输出 | 计算机、自动化 |
| **波形/频谱双视图** | 时域-频域对照 | 通信、信号 |
| **电路仿真** | 参数调节观察波形/响应 | 电气、电路 |
| **函数图像探究** | 观察参数对图像的影响 | 数学 |
| **证明探究** | 分步展开/折叠的证明 | 数学 |
| **复杂度对比** | 对比不同算法的时/空复杂度 | 计算机 |
| **拖拽排序** | 建立时序/流程/结构关系 | 算法、系统、流程类 |
| **分类匹配** | 区分概念/含义/现象 | 通信、电气、数学 |
| **图像/结构标注** | 强化视觉识别与空间理解 | 电路、结构、信号 |
| **学习记录表** | 结构化填写引导探究思维 | 实验/课程设计/研讨 |
| **评分量表（Rubric）** | 开放任务按维度打分 | 课程设计、研讨、报告 |

## 二、每个模块的推荐结构

一个模块通常包含以下 6 块：

```text
1. 引入问题（ABT 或任务驱动）
2. 核心讲解（定义/定理 + 公式渲染 + 直观说明）
3. 深层理解（五镜法选 2-3 个：看/拆/讲/比/迁）
4. 立刻练习（带即时反馈）
5. 纠错反馈（针对性诊断）
6. 小结迁移（一句话总结 + 一个迁移问题）
```

如果内容较难，可拆成两个子模块；不要在一个模块里同时塞进多个大难点。**数学推导类内容尤其要「逐步展开/折叠」，不要一次灌入整页推导。**

## 三、注意力重置点

高等教育每节 45 分钟课约对应 2-3 个注意力重置点；每次约 15-20 分钟插入一次：

- 从「看推导」切到「自己算一步」
- 从「听讲解」切到「自己判断对错」
- 从「输入」切到「输出」（口头/纸面复述定义）
- 从「抽象」切到「真实工程/科研案例」

**常见重置方式**：一个概念判断题、一个错例辨析、一个小仿真实验、一个一分钟复述任务、一个「预测结果再验证」。

## 四、高等教育互动设计规范（K-12 无）

### 4.1 公式必须真渲染

数学/物理/信号/电路类课件，行内/行间公式一律 KaTeX（优先）或 MathJax。禁止公式图片、纯文本、`x^2` 式写法。

```html
<!-- 行内 -->
<p>梯度 <span class="katex">\( \nabla f(x) \)</span> 指向函数增长最快的方向。</p>
<!-- 行间（可编号） -->
<div class="formula-box">\[ J(\theta) = \frac{1}{2m}\sum_{i=1}^{m}\bigl(h_\theta(x^{(i)}) - y^{(i)}\bigr)^2 \tag{1} \]</div>
```

### 4.2 推导分步组件

推导/证明用 `.derivation` 组件：编号步骤、可逐步展开/折叠、当前步高亮、可回溯。

```html
<div class="derivation">
  <div class="derivation-step" data-step="1">① 写出一阶泰勒展开……</div>
  <div class="derivation-step" data-step="2">② 方向导数沿单位向量 d……</div>
  <div class="derivation-step" data-step="3">③ 由 Cauchy-Schwarz 取等条件……</div>
</div>
```

### 4.3 算法必须可视化

计算机类课件的算法/数据结构，必须有**可运行的逐步可视化**（步骤高亮 + 复杂度对比），禁止只贴静态代码块。

```html
<div class="algo-viz" data-algo="insertion-sort">
  <!-- 数组条 + 当前比较位置高亮 + 复杂度对比表 -->
</div>
```

### 4.4 仿真的「控制变量」意识

理工实验/仿真必须明确控制变量三元组：**改变什么 / 保持不变 / 测量什么**。仿真区应提供参数控件（滑块/旋钮），并实时更新结果图/波形。

## 五、与 TeachAny 的对应

| TeachAny | TeachAnyHE |
|:---|:---|
| 生活化实验交互（溢水杯/跷跷板/冰面救人） | 工程/科研仿真（参数滑块+波形/频谱/电路/函数图） |
| 文本批注/情境对话卡 | 证明探究/公式渲染/算法可视化 |
| 图像/地图标注 | 图像/结构标注（电路/结构/信号） |
| 时间线/流程线 | 算法流程/系统时序 |
| AI 多模态互动区 | 保留（生成示意图/图表），但风格学术化 |
